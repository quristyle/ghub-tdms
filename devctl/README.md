# 개발서버 제어판

개발 장비에서 TDMS 를 띄우고 들여다보는 도구. **운영 배포와는 무관하다**
(운영은 `deploy/` 의 nginx + systemd 를 쓴다).

실행은 저장소 뿌리의 `dev.sh` 로 한다.

```bash
./dev.sh              # 브라우저 제어판 (http://localhost:7070)
./dev.sh tui          # 터미널 제어판
./dev.sh start        # 전부 시작
./dev.sh status       # 상태만 보기
```

## 브라우저 제어판

`./dev.sh` 를 인자 없이 실행하면 제어판 서버가 뜨고 브라우저가 열린다.

- 서비스 카드 — 상태·포트·pid·가동시간, 시작/중지/다시시작/로그/열기
- 데이터베이스 — 접속·표·마이그레이션 대기·자료 수·작업 큐 적체
- 점검·검증 — 환경 점검, 검증(타입체크+테스트+흐름), 빌드
- 콘솔 — 명령 출력을 실시간으로 흘리고, 탭을 바꾸면 서비스 로그를 따라간다

구현은 `server/panel.mjs` 와 `server/public/`. **의존성이 없다**(node:http 만 쓴다).

### 판정 로직을 복제하지 않는다

제어판 서버는 상태를 스스로 판단하지 않는다. `dev.sh status --json` 을 불러 그 결과를
그대로 전달하고, 버튼은 `dev.sh <명령>` 을 실행해 출력을 흘린다.
**터미널과 브라우저가 언제나 같은 것을 본다.**

### 안전

개발 도구라도 셸 명령을 돌리므로 네 겹으로 막는다.

| 막는 것 | 방법 |
|---|---|
| 바깥에서 닿는 것 | `127.0.0.1` 에만 묶는다 |
| DNS 재바인딩 | `Host` 머리글이 루프백 이름일 때만 받는다 |
| 다른 페이지의 폼 전송 | 바꾸는 요청에 `X-Devctl` 머리글을 요구한다 |
| 임의 명령 실행 | 허용 목록에 있는 명령만 받는다 (`rm -rf /` 같은 것은 400) |

포트를 바꾸려면 `DEVCTL_PORT=7071 ./dev.sh`, 브라우저를 자동으로 열지 않으려면 `DEVCTL_OPEN=0`.

## 폴더

```
devctl/
  server/
    panel.mjs    브라우저 제어판 서버 (의존성 없음)
    public/      index.html · panel.css · panel.js
  lib/
    common.sh    색·출력·.env 읽기·포트/프로세스 도구
    services.sh  서비스 정의(api·web·worker)와 기동·중지·상태
    checks.sh    사전 점검 (도구·설정·DB·포트)
    actions.sh   제어판이 하는 일들
    menu.sh      터미널 메뉴
    json.sh      상태를 JSON 으로 (브라우저 제어판이 읽는다)
  run/           PID 파일 (gitignore)
  logs/          서비스 로그 (gitignore)
```

## 다루는 서비스

| 이름 | 무엇 | 포트 | 기동 확인 |
|---|---|---|---|
| `api` | Fastify API | 8080 | `GET /health` |
| `web` | Vite 개발 서버 | 5173 | `GET /` |
| `worker` | Python 작업 워커 | — | 프로세스 생존 |

워커는 파이썬 가상환경이 있어야 쓸 수 있다. 없으면 제어판이 건너뛰고 준비 방법을 알려 준다.

## 알아 둘 것

- **제어판 밖에서 띄운 것도 알아본다.** PID 파일이 없으면 포트를 보고 찾으므로,
  터미널에서 직접 `pnpm dev` 로 띄운 것도 상태에 잡히고 `stop` 으로 끌 수 있다.
- **중지는 프로세스 나무를 통째로 끝낸다.** `pnpm → tsx/vite → node` 로 이어지는
  자식들을 차례로 끝내고, 그래도 포트를 쥐고 있으면 그 프로세스까지 정리한다.
- **로그는 `devctl/logs/` 에 쌓인다.** 서비스를 시작할 때마다 비운다.
- 제어판은 `.env` 를 읽기만 하고 고치지 않는다.

## 명령

| 명령 | 하는 일 |
|---|---|
| (없음) / `panel` | 브라우저 제어판 |
| `tui` | 터미널 제어판 |
| `start [서비스…]` | 시작 (생략하면 전부) |
| `stop [서비스…]` | 중지 |
| `restart [서비스…]` | 다시 시작 |
| `status` | 상태와 작업 큐 적체 |
| `logs [서비스]` | 로그. 서비스를 주면 따라가며 본다 |
| `doctor` | 도구·설정·DB·포트 점검 |
| `migrate` / `db` | 마이그레이션 적용 / 상태 |
| `seed` | 시험 자료 넣기 |
| `verify` | 타입체크 + 테스트 + 흐름 검증 |
| `build` | 운영 빌드 |
| `setup-worker` | 파이썬 가상환경 준비 |
| `open` | 브라우저로 열기 |
| `clean` | PID·로그 정리 |
