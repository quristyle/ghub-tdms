# 01. 프로젝트 개요

## 1. 배경

| 항목 | 내용 |
|---|---|
| 정식 과업 | 도면관리 시스템 구축 (₩422,200천, '26.2~9월, 8개월) |
| 근거 | DY SHE 2.0 설비안전 과업의 일환 |
| 현재 상태 | **내부 사정으로 홀드 (6개월째)** |
| 대응 | 설비기술팀 CM이 **최소 기능 자체 구축** |
| 유지관리 | 추후 전문업체 활용 예정 |

## 2. 현재 문제 (As-Is) — 정식 과업 기획서에서 발췌

- **개인 소유화**: 도면·기술자료가 개인 PC 및 공유폴더에 분산 저장
- **중복 저장 및 버전 혼선**: 최신본·이력 관리 곤란
- **자료 신뢰성 저하**: 최종본 확인 어려움
- **관리 비효율**: 검색·보존·이력 관리 비체계적
- **보안 취약**: 협력업체에 **이메일로 원본 파일 배포** → 정보 유출, 사후 관리 불가

## 3. 자체 구축의 목표 (재정의)

정식 시스템의 축소판이 아니라, **"정식 과업이 재개되면 그대로 이관되는 도면 데이터베이스"**를 만든다.

> 정식 과업 예산 중 "도면 분석 및 데이터 구축 컨설팅"이 ₩137,200천(전체의 33%)이다.
> 이 부분을 CM이 미리 완성해두면, **홀드가 풀리든 안 풀리든 낭비가 아니다.**
> 이것이 사내 보고 논리이자 이 프로젝트의 존재 이유다.

## 4. 개발 범위

### 4.1 1차 개발 (MVP, 최소기능제품) — **도면(DRAWING)만**

| 기능 | 내용 |
|---|---|
| **등록** | 도면 일괄 등록. 폴더 경로에서 메타데이터 자동 추출 |
| **검색·조회** | 트리 탐색 + 속성 검색 (도면번호, 공종, 구역, AG/UG) |
| **열람** | **PDF 웹 뷰어** (PDF.js). DWG는 다운로드 |
| **리비전 관리** | Rev 이력, 구본(Superseded) 보관. **삭제 기능 없음** |
| **협력사 배포** | 만료형 다운로드 링크 발송 + 워터마크 PDF |
| **대여 현황 (Check Out)** | "A업체 대여중" 표시. 중복 대여 시 경고 |
| **입고·검수** | 협력사 업로드 → 담당자 검수 → Rev 승인·등록 |
| **미입고 관리** | 배포했으나 회수 안 된 도면 목록 |
| **배포 이력** | 누가/언제/어느 업체에/어느 Rev를 받아갔는지 |
| **권한** | 3종: 관리자 / 사내 사용자 / 협력사 |

### 4.2 2차 확장 (나중에) — MDB/IDB

- Mechanical & Inspection Data Book, Technical Data Book, 안전관련, 마감보고서
- **검색·열람 전용.** 리비전·대여·검수 불필요 (고정 기록이므로)
- **1차 설계 시 DB에 `자료종류(doc_class)` 필드를 미리 확보** → 재개발 없이 증축 가능

### 4.3 **명시적 제외 (하지 않는다)**

| 제외 항목 | 이유 |
|---|---|
| Ocean-H(설비관리시스템) 연동 | 자체 구현 불가. 단, **설비 Tag를 메타데이터로 보유**하여 향후 연동 여지만 확보 |
| 웹에서 DWG 직접 열람 | 무료 방법 없음. 상용 SDK는 유료/보안 이슈 |
| DWG 내 설비정보 자동 추출 | 자체 구현 불가 |
| 도면 본문 텍스트 검색 (Full-Text) | 자체 구현 난이도 과다 |
| Smart Tagging / P&ID Link | 자체 구현 불가 |
| DRM | 워터마크 + 배포이력 추적으로 대체 |
| SSO 연동 | 로컬 계정으로 대체 |
| 도면 자동 병합 | **기술적으로 불가능** (아래 참조) |

## 5. 반드시 알아둘 한계 — A·B 업체 동시 수정

CAD 도면은 **자동 병합(auto-merge)이 불가능하다.** 시스템이 할 수 있는 최대치:

1. B업체 요청 시 → **"A업체 대여중(2026-07-01)" 경고 표시**
2. A본/B본을 **분기 리비전(Rev C-a / Rev C-b)**으로 각각 보관
3. **"통합 필요(Merge Required)" 상태**를 강제 부여
4. **사내 담당자가 CAD(캐디안)로 직접 통합** → 통합본만 정식 Rev C로 승인

> 시스템은 "놓치지 않게 만드는 장치"이지, "대신 합쳐주는 도구"가 아니다.
> 이 부분은 반드시 **절차서(프로세스)**로 보완해야 한다.
