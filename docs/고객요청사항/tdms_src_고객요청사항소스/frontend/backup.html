백업 만들기

만드는 동안에는 자료를 등록·반입하지 말아 주십시오. 그 사이에 자료가 바뀌면 백업의 시점이 어긋납니다.
외장하드에 바로 만들 때 쓰는 예비 방법입니다. 풀 필요가 없지만 화면에서 내려받을 수는 없습니다(TDB·MDB만).
변경분은 TDB·MDB 도면 파일만 됩니다. 처음이라면 전체 백업을 먼저 만들어야 합니다.
