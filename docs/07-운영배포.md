# 07. 운영·배포

## 1. 서버 구성 (Ubuntu 24.04)

| 서비스 | 유닛 | 실행 계정 |
|---|---|---|
| 리버스 프록시 | `nginx.service` | `www-data` |
| API | `tdms-api.service` | `tdms-api` |
| 워커 | `tdms-worker@1.service`, `@2` | `tdms-worker` |
| DB | `postgresql@16-main.service` | `postgres` |

### 설치가 필요한 외부 프로그램
PostgreSQL 16, Node 22, Python 3.12, LibreOffice(오피스→PDF),
ODA File Converter(DWG→PDF), pgBackRest, restic.

## 2. nginx

```nginx
server {
  listen 443 ssl; http2 on;
  server_name tdms.example.internal;

  ssl_protocols TLSv1.2 TLSv1.3;
  ssl_session_cache shared:SSL:10m;  ssl_session_tickets off;
  add_header Strict-Transport-Security "max-age=31536000" always;

  # 접근 제한을 여기로 올린다 — 프록시 뒤에서 무력화되던 문제(S-08) 해소
  include /etc/nginx/tdms-allow.conf;    # allow 10.0.0.0/8; deny all;
  real_ip_header X-Forwarded-For;
  set_real_ip_from 10.0.0.0/8;

  client_max_body_size 2g;               # 업로드 무제한 문제 해소
  client_body_temp_path /srv/tdms/tmp;

  brotli on;
  brotli_types text/css application/javascript application/json image/svg+xml;

  # 보안 헤더 (기존 정책 유지)
  add_header X-Content-Type-Options nosniff always;
  add_header X-Frame-Options DENY always;
  add_header Referrer-Policy same-origin always;

  location /assets/ {
    root /srv/tdms/web;
    expires 1y; add_header Cache-Control "public, immutable";
  }

  location / {
    root /srv/tdms/web; try_files $uri /index.html;
    add_header Cache-Control "no-cache";
  }

  location /api/ {
    proxy_pass http://unix:/run/tdms/api.sock;
    proxy_http_version 1.1;
    proxy_buffering off;          # SSE 진행률
    proxy_read_timeout 300s;
    proxy_set_header X-Request-Id $request_id;
  }

  location /_blob/ {
    internal;
    alias /srv/tdms/blobs/;
    sendfile on; tcp_nopush on; aio threads;
    output_buffers 4 256k;
  }
}
```

## 3. systemd

```ini
# tdms-api.service
[Service]
Type=notify
User=tdms-api
WorkingDirectory=/srv/tdms/app
ExecStart=/usr/bin/node --enable-source-maps dist/main.js
Environment=NODE_ENV=production
LoadCredential=db-password:/etc/tdms/db-password      # 평문 .env 대체
LoadCredential=session-secret:/etc/tdms/session-secret
RuntimeDirectory=tdms
NoNewPrivileges=yes
PrivateTmp=yes
ProtectSystem=strict
ProtectHome=yes
ReadWritePaths=/srv/tdms/blobs /srv/tdms/tmp
MemoryMax=1G
Restart=always
RestartSec=2
```

```ini
# tdms-worker@.service
[Service]
User=tdms-worker
ExecStart=/srv/tdms/worker/.venv/bin/python -m tdms_worker --id %i
LoadCredential=db-password:/etc/tdms/db-password
NoNewPrivileges=yes
PrivateTmp=yes
PrivateNetwork=yes          # 변환 워커는 네트워크가 필요 없다
ProtectSystem=strict
ProtectHome=yes
ReadWritePaths=/srv/tdms/blobs /srv/tdms/tmp
MemoryMax=2G
CPUWeight=50                # 조회 요청보다 우선순위 낮게
Restart=always
```

> `PrivateNetwork=yes` 인 워커는 DB에 유닉스 소켓으로만 붙는다.
> DB가 원격이면 이 옵션을 끄고 대신 방화벽으로 egress를 제한한다.

## 4. 배포

```bash
# 빌드 아티팩트 교체 → 무중단 리로드
rsync -a --delete dist/web/ /srv/tdms/web/
rsync -a --delete dist/api/ /srv/tdms/app/
sudo systemctl reload tdms-api      # 기존 연결 드레인 후 교체
```

- DB 마이그레이션은 **배포 전**에 별도로 적용한다(`pnpm db:migrate`).
- 호환 불가 변경은 2단계로 나눈다(컬럼 추가 → 배포 → 구 컬럼 제거).
- 인프라 전체는 **Ansible 플레이북 1개**로 재현한다. 서버가 날아가도 1회 실행으로 복구된다.

## 5. 백업

| 대상 | 수단 | 주기 | 보존 |
|---|---|---|---|
| DB | **pgBackRest** (전체 + 증분 + WAL 아카이브) | 전체 주1 / 증분 일1 | 90일, PITR |
| blob | **restic** (중복제거·암호화) | 일 1회 | 90일 |
| 설정 | Ansible 플레이북 = Git | 커밋 시 | 영구 |

**백업 관리 화면은 그대로 유지한다.** 내부 구현만 pgBackRest/restic 호출로 바뀌고,
CM이 보는 화면(지금 상태·만들기·이력·받기·비고·파일 삭제)은 동일하다.

복구 리허설을 **분기 1회** 수행하고 결과를 `docs/운영기록/` 에 남긴다.

## 6. 관측

| 항목 | 수단 |
|---|---|
| 로그 | `pino` JSON → journald (`journalctl -u tdms-api`) |
| 로그 보존 | journald `SystemMaxUse=2G`, 30일 |
| 지표 | `/api/metrics` (Prometheus 포맷) |
| 느린 쿼리 | PostgreSQL 로그 + `pg_stat_statements` |
| 헬스체크 | `GET /health` — DB 연결·큐 상태 포함 |

## 7. 보안 운영

| 항목 | 주기 |
|---|---|
| OS 보안 패치 (`unattended-upgrades`) | 자동 |
| 의존성 CVE (`pnpm audit`, `pip-audit`) | CI 매 실행 |
| PDF.js 업스트림 추적 | 월 1회 (`patch-package` 로 2줄 패치 유지) |
| 접근 허용 IP 목록 검토 | 분기 1회 |
| 계정 棚卸 (퇴직자·미사용) | 분기 1회 |
| 감사 로그 이상 조회 (대량 다운로드) | 월 1회 |

## 8. 비밀값 관리

```
/etc/tdms/db-password        0600 root:root
/etc/tdms/session-secret     0600 root:root
```
systemd `LoadCredential=` 로 프로세스에 전달한다. 저장소에는 `.env.example` 만 둔다.
`.env` 는 `.gitignore` 에 있으며, 커밋 전 `gitleaks` 로 한 번 더 막는다.
